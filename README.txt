RAJKIYE DEGREE MAHAVIDYALAYA, RAMGARHWA — MULTI-PAGE WEBSITE

Files to upload together into the ROOT of the same GitHub repository:
- index.html (homepage)
- about.html
- academics.html
- faculty.html
- notices.html
- facilities.html
- contact.html

All main homepage sections link to dedicated pages and open in a new browser tab. Each subpage includes navigation links to other sections and a link back to the homepage.

Free publishing with GitHub Pages:
1. Create/open your GitHub repository.
2. Upload all seven HTML files to the same top-level/root folder (not inside a subfolder).
3. Open Settings -> Pages.
4. Choose deploy from the main branch and /(root), then save.
5. Open the published URL shown in Settings -> Pages.

Important:
- The faculty page includes the 11 supplied names, all labelled Assistant Professor.
- Verify all institutional claims, course offerings, contact details, facilities, affiliation, and notices before public release.
- Replace the temporary emblem and stock images with college-approved assets.
- This is a static site; it does not have a database, admin login, or automated notice management yet.
